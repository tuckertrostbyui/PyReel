## v0.1.0 (2026-03-26)

- First release of `pyreel`!
- Reddit post fetching via PRAW
- Text sanitization (Reddit formatting, markdown, NSFW filter)
- Edge TTS speech synthesis with mp3→wav conversion
- WhisperX word-level timestamp alignment
- B-roll fetching: yt-dlp (YouTube), Pexels, Pixabay, local file
- 9:16 portrait crop (CENTER and CUSTOM strategies)
- Four subtitle styles: BOLD_WHITE, HIGHLIGHT, ALLCAPS, ROLLING
- MoviePy video composition (1080x1920, libx264/aac, 30fps)
- LiteLLM-powered LLM integration: rewrite, summarize, split, write (opt-in)
- Checkpoint-based resumable pipeline (12 stages)
- Metadata bundle output (title, description, hashtags, platforms)
- Structured output directory with broll_sources.txt attribution log
